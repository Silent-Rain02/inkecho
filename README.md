# InkEcho

InkEcho 是一个用于文学作品对话、续写和二次创作的项目。

## 项目简介

项目围绕文学作品内容，提供便于阅读、讨论、角色对话和创意改写的创作空间。

## 当前状态

当前已完成一个可切换模型服务的单页 MVP 原型。

## 已实现

- 作品名称、时代氛围和世界观备注
- 作品级参考片段，可粘贴或导入 `.txt` / `.md` 文件，并随项目保存
- 剧情摘要字段，帮助模型在长对话中记住关键事件和当前悬念
- 本次创作要求字段，可指定文风、叙事视角、禁用元素和改写边界
- 角色卡切换、自定义角色添加、编辑与删除
- 续写、改写、角色独白三种创作模式，并为每种模式提供独立写作约束
- 项目级创作倾向：克制叙事、平衡、大胆想象
- 项目级回复长度：精简、标准、展开，并作用于流式生成预算
- 对话消息发送、快捷键发送和会话重置
- 最后一轮用户提问支持编辑后重新发送
- 会话工具菜单支持复制当前对话、导出和重新开始
- 创作灵感卡片，可一键填入写作提示
- 支持按项目保存自定义灵感卡片，可一键使用、编辑或删除
- 模型服务切换：办公网自定义 Azure、Ollama、OpenAI、Azure OpenAI、OpenAI-compatible
- 模型状态会按当前选择的模型名判断，直接在界面填写 `qwen3:8b` 也能正确显示 Ollama 配置状态
- 支持从 Ollama、OpenAI 和 OpenAI-compatible 服务读取可用模型列表
- Ollama 本地模型支持，可配置 `qwen3:8b` 等模型
- 模型流式输出，回复会逐字出现在对话框中
- 模型回复保留原有换行，连接状态会区分配置、连接成功、连接失败和离线演示
- 健康检查和模型列表读取带有超时保护，切换服务时不会被旧请求覆盖状态
- 后端提供健康检查、模型列表和聊天接口的 HTTP 路由回归测试
- 支持中途停止模型生成，并保留已经生成的内容
- 角色回复支持一键复制
- 最后一条角色回复支持一键重试，便于重新生成不同版本
- 重试后的角色回复会保留多个版本，可在消息下方切换并选择继续对话的版本
- 支持在当前对话中搜索关键词，快速定位角色、情节和旧回复
- 浏览器本地自动保存对话、作品设定和模型选择
- 本地存储失败时会提示先导出 JSON 备份，避免误以为内容已经保存
- 当前未发送的文字按项目自动保存，切换项目或刷新后可恢复
- 一键将作品设定、角色卡和对话记录导出为 Markdown
- 支持在浏览器中创建、切换和删除多个创作项目
- 项目数量上限为 50 个，创建、复制和导入共用同一上限
- 支持复制当前项目创建平行创作支线，并保留完整上下文
- 支持将全部项目导出为 JSON 备份，并导入到另一台设备
- 对话记录保存说话者信息，自定义角色可填写性格与语气

模型服务不可用时，页面会自动回退到演示回复。

## 配置模型服务

复制 `.env.example` 为 `.env`，按需填写配置。真实密钥只放在本地环境变量中，不要提交到 GitHub。

办公网自定义服务使用以下配置：

```bash
INK_ECHO_PROVIDER=custom_azure
INK_ECHO_CUSTOM_AZURE_API_KEY=你的密钥
INK_ECHO_CUSTOM_AZURE_ENDPOINT=https://aidp-i18ntt-sg.tiktok-row.net/api/modelhub/online/v2/crawl
INK_ECHO_CUSTOM_AZURE_MODEL=gpt-5-mini-2025-08-07
INK_ECHO_CUSTOM_AZURE_LOGID=你的logid
```

如果使用 Ollama：

`INK_ECHO_OLLAMA_BASE_URL` 可以省略，默认连接本机 `http://127.0.0.1:11434/v1`。

```bash
INK_ECHO_PROVIDER=ollama
INK_ECHO_OLLAMA_BASE_URL=http://127.0.0.1:11434/v1
INK_ECHO_OLLAMA_MODEL=qwen3:8b
```

## 本地运行

纯前端演示可以直接双击 `index.html` 打开；要连接模型服务，请启动 Python 服务：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 server.py
```

然后访问 <http://localhost:5173>。
